Unit 4 — Securing Devices

~23 class periods · Analyze Risk · Mitigate Risk · Detect Attacks
UNIT FOUNDATION

Device security: the host is another defense-in-depth layer

Units 1–3 cover people, physical spaces, and networks. Unit 4 focuses on the individual device: the system that executes software, stores data, authenticates users, and provides services.

1. AssetWhat device, data, service, or operation matters?
2. DeviceServer, personal computer, handheld, embedded computer, or IoT?
3. VulnerabilityWhat weakness exists?
4. AttackHow does the adversary exploit it?
5. ImpactWhat can the attacker steal, control, encrypt, destroy, or disrupt?
6. ControlWhich control interrupts the attack path?
7. EvidenceWhat logs, files, settings, processes, or login patterns reveal it?
Core idea: a device is not secure merely because the surrounding network is secure. Host-level controls provide another layer when an adversary reaches the device.
UNIT 4 MASTERY MAP
TopicYou should be able to...
4.1Classify devices; identify all AP malware types; trace unpatched software, weak authentication, BIOS/UEFI exposure, autorun, open ports, firewall gaps, and anti-malware gaps to consequences; rate device risk.
4.2Explain hash properties/collisions; explain password hashing; distinguish online/offline, brute-force, dictionary, spraying, and credential-stuffing attacks; identify authentication factors; configure login settings.
4.3Identify managerial controls; explain signature-based anti-malware; explain patching; configure and reason through host-based firewall ACLs, including outbound traffic and first-match ordering.
4.4Classify host/file/behavior IoCs; choose detection based on performance, cost, and criticality; evaluate detection tradeoffs; recognize password attacks from authentication logs.
