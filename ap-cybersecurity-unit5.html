Unit 5 — Securing Applications and Data

~30 class periods · Analyze Risk · Mitigate Risk · Detect Attacks · Content-focused master study guide
Unit foundation

The final defense-in-depth layer: applications and data

Unit 5 combines application security, file permissions, data classification, cryptography, secure development, and detection. For every scenario, trace the chain from asset → vulnerability → attack → impact → control → evidence.
Asset → What application/data matters? → Vulnerability → What weakness exposes it? → Attack → How is it exploited? → Impact → Confidentiality / Integrity / Availability → Control → What interrupts the attack path? → Evidence → What logs, hashes, or access events reveal it?
Unit 5 distinction: encryption protects confidentiality, hashing can verify integrity, access control governs who can perform operations, sanitization prevents malicious input from changing application behavior, and logging/detection provides evidence. Do not treat these controls as interchangeable.
