Unit 3 — Securing Networks

~26 class periods · Skills emphasized: Analyze Risk · Mitigate Risk · Detect Attacks
Unit foundation

How to Think About a Network Security Problem

Unit 3 is not primarily a vocabulary unit. You need to reason from network architecture → vulnerability → attack path → impact → control → evidence. The same network can have multiple vulnerabilities, and one vulnerability can enable multiple attacks.

The network security chain

Asset → what communication/system matters?  →  Vulnerability → what network weakness exists?  →  Attack → how is it exploited?  →  Impact → confidentiality, integrity, or availability?  →  Mitigation → what control interrupts the path?  →  Detection → what evidence would reveal it?

When reading a scenario, do not jump straight from a technical detail to a control. First determine what the weakness actually enables. An open switch port is not itself a MAC flooding attack; weak segmentation is not itself lateral movement. The vulnerability creates an opportunity, and the attack is the adversary's use of that opportunity.

Minimum network vocabulary you should understand before studying the attacks

IP ADDRESSLogical address used to identify a network interface for IP communication.
MAC ADDRESSLink-layer address associated with a network interface on a local network.
SWITCHConnects devices on a LAN and forwards Ethernet frames based on MAC addresses.
ROUTER / GATEWAYConnects networks and forwards IP traffic between them. A default gateway is the device a host uses to reach destinations outside its local network.
DNSTranslates domain names into IP addresses so users can reach network services by name.
ARPAssociates an IPv4 address with a MAC address on a local network.
PORTA logical endpoint used by transport-layer services. A firewall can filter traffic by port.
PROTOCOLA defined set of rules for communicating, such as TCP, UDP, ICMP, HTTP, or HTTPS.
LANLocal area network containing devices that communicate within a local organization or physical area.
WAPWireless access point that provides wireless connectivity to a network.
Unit 3 mastery map
TopicYou should be able to...
3.1Recognize ARP poisoning, MAC flooding, DNS poisoning, and smurf attacks; trace how network vulnerabilities enable attacks; rate network risk.
3.2Identify router, switch, VPN, and wireless security policies; explain wireless authentication, encryption, beacon control, signal control, and MAC filtering.
3.3Distinguish DMZs, subnets, and VLANs and explain segmentation as a way to contain breaches and apply different security policies.
3.4Distinguish stateless/stateful/NGFW firewalls; read ACLs in order; determine effective firewall placement; configure rules based on IP, port, protocol, service, application, direction, and action.
3.5Distinguish NIDS/NIPS/SIEM; explain AI thresholds; choose signature/anomaly/hybrid detection; evaluate speed, cost, false positives, and false negatives; identify network IoCs from evidence.
The unifying principle: every network-security question is asking some version of “What path does the adversary have, what can they accomplish through that path, what control should interrupt it, and what evidence would tell us whether the attack happened?”
